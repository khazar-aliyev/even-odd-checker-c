# 🔢 Even or Odd Number Checker

A concise, efficient C command-line program that evaluates an integer entered by the user and checks if it is even or odd. 

This project demonstrates the use of integer modulo arithmetic (`%`) and compact inline conditional logic via the **ternary operator** (`? :`).

---

## 🚀 Features
* **Integer Input Handling:** Safely reads user numeric input using `scanf` and `int` data types.
* **Modulo Arithmetic:** Uses the remainder operator to evaluate divisibility by 2.
* **Ternary Conditional Operator:** Implements a clean, one-line alternative to traditional `if-else` blocks for outputting the result.

---

## 💻 Tech Stack
* **Language:** C (C99 standard)
* **Compiler:** Apple Clang
* **Environment:** macOS, VS Code, Terminal
